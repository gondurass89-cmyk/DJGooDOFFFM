Архитектура

Проект состоит из 4 основных частей, работающих вместе:

TELEGRAM

Мобильное приложение

↓ Пользователь открывает Mini App

FRONTEND (Next.js)

React + Tailwind CSS + Framer Motion

↓ API запросы

CLOUDFLARE WORKERS

nowplaying-worker
listeners-worker

↓ Запрос метаданных

AZURACAST

Radio Server (Liquidsoap + Icecast)

Быстрый старт

Клонирование репозитория

git clone https://github.com/ваш-username/djgoodoff-fm.git

Установка зависимостей

npm install — устанавливает все необходимые пакеты

Настройка переменных окружения

Создайте .env.local с URL вашего AzuraCast сервера и Cloudflare Workers

Запуск разработки

npm run dev — запускает сервер разработки на localhost:3000

Деплой на Vercel

Подключите репозиторий к Vercel для автоматического деплоя

Переменные окружения

# URL вашего AzuraCast сервера
NEXT_PUBLIC_AZURACAST_URL=https://your-radio-server.com

# URL Cloudflare Workers
NEXT_PUBLIC_LISTENERS_WORKER=https://listeners.ваш-аккаунт.workers.dev
NEXT_PUBLIC_NOWPLAYING_WORKER=https://nowplaying.ваш-аккаунт.workers.dev

# Telegram Bot Token
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
