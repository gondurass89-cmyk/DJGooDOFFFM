1. Описание проекта

Что это за проект?

DJ GooD OFF FM — это Telegram Mini App для прослушивания онлайн-радио прямо в мессенджере Telegram. Приложение работает как веб-сайт, который открывается внутри Telegram и выглядит как нативное приложение.

Какие задачи решает?

  • Прослушивание радио без установки отдельных приложений — пользователь просто открывает Mini App в Telegram
  • Отображение названия текущего трека — автоматически обновляется каждые 5 секунд
  • Визуальный эквалайзер — показывает частоты звука в реальном времени
  • Настройка звука — 3-полосный эквалайзер (Bass/Mid/Treble) + усиление громкости до 250%
  • Подсчёт слушателей — показывает сколько человек слушают радио прямо сейчас
  • Загрузка обложек — автоматически ищет обложки треков в Last.fm и Apple Music

Как работает (простым языком)?

ПОЛЬЗОВАТЕЛЬ открывает Telegram → нажимает на Bot → открывается Mini App
                                        ↓
                        Мини-приложение загружается с сервера Vercel
                                        ↓
                        Приложение подключается к аудиопотоку AzuraCast
                                        ↓
                        Пользователь слышит музыку и видит название трека

Важные понятия:

  • Telegram Mini App — веб-страница, которая открывается внутри Telegram как приложение
  • AzuraCast — программа на сервере, которая вещает радио в интернет
  • Cloudflare Worker — маленькая программа в облаке, которая передаёт данные между сервером и приложением

5. ПОЛНЫЙ ТУТОРИАЛ ДЛЯ НОВИЧКА

Важно: Этот туториал написан для человека, который никогда не поднимал сервер и не работал с радио. Каждый шаг объясняется подробно.

ШАГ 1 — Установка нужных программ

1.1 Установка Node.js

Windows:

Скачайте Node.js

Откройте браузер и перейдите на https://nodejs.org. Скачайте версию "LTS" (Long Term Support).

Установите

Запустите скачанный файл (.msi) и нажимайте "Next" на всех экранах.

Перезагрузите

После установки перезагрузите компьютер.

macOS:

brew install node

Linux (Ubuntu/Debian):

sudo apt update
sudo apt install nodejs npm
node --version  # Должно показать v18.x.x или выше
npm --version   # Должно показать 9.x.x или выше

1.2 Установка Git

Windows: Скачайте с https://git-scm.com/download/win и установите.

macOS:

git --version  # Если не установлен, система предложит установить

Linux:

sudo apt install git

1.3 Регистрация на сервисах

Vercel

Перейдите на https://vercel.com → Sign Up → Continue with GitHub

Cloudflare

Перейдите на https://dash.cloudflare.com/sign-up → Введите email и пароль

ШАГ 2 — Настройка радио (AzuraCast)

Если у вас уже есть работающий радио-сервер, пропустите этот шаг.

AzuraCast — это бесплатная программа для создания интернет-радио. Она включает:

  • Liquidsoap — программа для вещания музыки
  • Icecast — сервер для раздачи аудиопотока
  • Web-интерфейс — для управления плейлистами

Установка на сервер

# Подключитесь к серверу
ssh root@IP_АДРЕС_СЕРВЕРА

# Установите Docker
curl -fsSL https://get.docker.com | sh

# Установите AzuraCast
mkdir -p /var/azuracast
cd /var/azuracast
curl -fsSL https://raw.githubusercontent.com/AzuraCast/azuracast/main/docker.sh > docker.sh
chmod a+x docker.sh
./docker.sh install

# Откройте в браузере: http://IP_АДРЕС_СЕРВЕРА

ШАГ 3 — Настройка Telegram Mini App

3.1 Создание Telegram Bot

Найдите @BotFather

Откройте Telegram и найдите @BotFather

Создайте бота

Отправьте команду /newbot и следуйте инструкциям

Сохраните токен

BotFather пришлёт токен вида 1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

3.2 Настройка Mini App

# Клонируйте репозиторий
git clone https://github.com/ваш-username/djgoodoff-fm.git
cd djgoodoff-fm

# Установите зависимости
npm install

# Создайте .env.local
NEXT_PUBLIC_AZURACAST_URL=https://your-radio-server.com
NEXT_PUBLIC_LISTENERS_WORKER=https://listeners.ваш-аккаунт.workers.dev
NEXT_PUBLIC_NOWPLAYING_WORKER=https://nowplaying.ваш-аккаунт.workers.dev

# Запустите
npm run dev

ШАГ 4 — Деплой на Vercel

Подключите репозиторий

Войдите на Vercel → Import Project → выберите репозиторий

Настройте переменные окружения

Добавьте все переменные из .env.local в настройки проекта

Деплой

Нажмите Deploy. Vercel автоматически соберёт и разместит проект

HTTPS обязателен! Telegram Mini App работает только по HTTPS. Vercel автоматически выдаст SSL сертификат.
