# DJ GooD OFF FM — Telegram Mini App для онлайн-радио

---

## 1. Описание проекта

### Что это за проект?

**DJ GooD OFF FM** — это Telegram Mini App для прослушивания онлайн-радио прямо в мессенджере Telegram. Приложение работает как веб-сайт, который открывается внутри Telegram и выглядит как нативное приложение.

### Какие задачи решает?

1. **Прослушивание радио без установки отдельных приложений** — пользователь просто открывает Mini App в Telegram
2. **Отображение названия текущего трека** — автоматически обновляется каждые 5 секунд
3. **Визуальный эквалайзер** — показывает частоты звука в реальном времени
4. **Настройка звука** — 3-полосный эквалайзер (Bass/Mid/Treble) + усиление громкости до 250%
5. **Подсчёт слушателей** — показывает сколько человек слушают радио прямо сейчас
6. **Загрузка обложек** — автоматически ищет обложки треков в Last.fm и Apple Music

### Как работает (простым языком)?

```
ПОЛЬЗОВАТЕЛЬ открывает Telegram → нажимает на Bot → открывается Mini App
                                    ↓
                    Мини-приложение загружается с сервера Vercel
                                    ↓
                    Приложение подключается к аудиопотоку AzuraCast
                                    ↓
                    Пользователь слышит музыку и видит название трека
```

**Важные понятия:**
- **Telegram Mini App** — веб-страница, которая открывается внутри Telegram как приложение
- **AzuraCast** — программа на сервере, которая вещает радио в интернет
- **Cloudflare Worker** — маленькая программа в облаке, которая передаёт данные между сервером и приложением

### Интерфейс приложения

```
┌─────────────────────────────────────┐
│         [LOGO] DJ GooD OFF FM       │  ← Заголовок с логотипом
│                                     │
│    ┌─────────────────────────┐      │

│    │   (зелёные символы)     │      │
│    └─────────────────────────┘      │
│                                     │
│    ┌─────────────────────────┐      │
│    │ ▓▓▓▓▓▓▓▓░░░░▓▓▓░░░░░░▓ │      │  ← Визуализатор (24 полосы)
│    │ BASS    MID    TREBLE   │      │     Bass=розовый, Mid=зелёный, Treble=голубой
│    └─────────────────────────┘      │
│                                     │
│    ♫ Artist - Title (Running) ♫     │  ← Бегущая строка с названием трека
│                                     │
│         👥 5 слушателей             │  ← Счётчик слушателей
│                                     │
│    ┌─────────────────────────┐      │

│    └─────────────────────────┘      │
│                                     │
│    🔊 Громкость: ████████░░ 80%     │  ← Слайдер громкости
│                                     │
│    ▼ Эквалайзер                     │  ← Раскрывающийся блок
│    ┌─────────────────────────┐      │
│    │ Bass   ████████░░  +6   │      │  ← 3 слайдера эквалайзера
│    │ Mid    ████░░░░░░  +2   │      │
│    │ Treble ██████████ +8    │      │

│    └─────────────────────────┘      │
└─────────────────────────────────────┘
```

### Основные функции

1. **Play/Pause** — запуск и остановка воспроизведения
2. **Громкость** — регулировка от 0% до 250% (с усилением)
3. **Эквалайзер** — настройка Bass/Mid/Treble от -12 до +12 dB
4. **Пресеты** — готовые настройки: Flat, Bass, Electronic, Rock, Vocal, Club
5. **Бегущая строка** — показывает название трека с эффектом Matrix
6. **Обложка** — автоматический поиск обложки альбома

```

                    │
```

### ШАГ 2 — Настройка радио (AzuraCast)

> **Примечание:** Если у вас уже есть работающий радио-сервер, пропустите этот шаг.

#### 2.1 Что такое AzuraCast?

AzuraCast — это бесплатная программа для создания интернет-радио. Она включает:
- **Liquidsoap** — программа для вещания музыки
- **Icecast** — сервер для раздачи аудиопотока
- **Web-интерфейс** — для управления плейлистами

#### 2.2 Варианты установки AzuraCast

**Вариант А: Свой сервер (рекомендуется для production)**

1. Арендуйте VPS сервер (минимум 2 GB RAM):
   - DigitalOcean — от $12/мес
   - Hetzner — от €4/мес
   - Timeweb, Selectel (Россия) — от 300₽/мес

2. Подключитесь к серверу по SSH:
   ```bash
   ssh root@IP_АДРЕС_СЕРВЕРА
   ```

3. Установите Docker:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```

4. Установите AzuraCast:
   ```bash
   mkdir -p /var/azuracast
   cd /var/azuracast
   curl -fsSL https://raw.githubusercontent.com/AzuraCast/azuracast/main/docker.sh > docker.sh
   chmod a+x docker.sh
   ./docker.sh install
   ```

5. Дождитесь установки (10-15 минут)

6. Откройте в браузере: `http://IP_АДРЕС_СЕРВЕРА`
   - Первый раз вас попросят создать администратора

**Вариант Б: Локально через Docker Desktop (Windows/macOS)**

1. Установите Docker Desktop: https://www.docker.com/products/docker-desktop

2. Выполните те же команды что и выше, но на своём компьютере

3. Откройте в браузере: `http://localhost:80`

> ⚠️ **Проблемы Docker Desktop на Windows:**
> - Требует WSL2 (Windows Subsystem for Linux)
> - Может конфликтовать с антивирусами
> - Медленно работает с большими файлами
> - Требует много ресурсов (4+ GB RAM)
> - Hyper-V может конфликтовать с VirtualBox
>
> **Если Docker не работает — используйте Вариант В (VirtualBox)**

**Вариант В: VirtualBox (РЕКОМЕНДУЕТСЯ ДЛЯ WINDOWS)**

> VirtualBox — это программа для запуска виртуальных компьютеров. Вы создаёте "компьютер внутри компьютера" с Linux, где всё работает надёжно.

#### 2.2.1 Скачивание и установка VirtualBox

1. **Скачайте VirtualBox:**
   - Перейдите на https://www.virtualbox.org/wiki/Downloads
   - Нажмите "Windows hosts"
   - Скачайте файл (~100 MB)

2. **Установите VirtualBox:**
   - Запустите скачанный файл
   - Нажимайте "Next" на всех экранах
   - Согласитесь на установку сетевых драйверов (предупреждение о разрыве соединения — нормально)
   - Нажмите "Install"
   - После установки перезагрузите компьютер

3. **Скачайте образ Linux (Ubuntu Server):**
   - Перейдите на https://ubuntu.com/download/server
   - Выберите "Option 2 - Manual server installation"
   - Скачайте ISO-образ (~1.5 GB)

#### 2.2.2 Создание виртуальной машины

1. **Запустите VirtualBox** (иконка на рабочем столе или в меню Пуск)

2. **Создайте новую машину:**
   - Нажмите кнопку "Создать" (синяя звёздочка)
   - **Имя:** `AzuraCast` (или любое)
   - **Папка:** оставьте по умолчанию или выберите папку с достаточным местом (20+ GB)
   - **Образ ISO:** нажмите на значок папки → выберите скачанный Ubuntu ISO
   - Нажмите "Далее"

3. **Настройка ресурсов:**
   - **Основная память (RAM):** минимум 2048 MB (2 GB), рекомендуется 4096 MB (4 GB)
   - **Процессоры:** минимум 2, рекомендуется 4
   - Нажмите "Далее"

4. **Виртуальный жёсткий диск:**
   - Размер: минимум 20 GB, рекомендуется 40 GB
   - Нажмите "Далее" → "Готово"

5. **Финальные настройки:**
   - В списке машин выберите "AzuraCast"
   - Нажмите "Настроить" (жёлтая шестерёнка)

#### 2.2.3 Настройка сети VirtualBox (КРИТИЧНО!)

> Без правильной настройки сети радио НЕ будет доступно из интернета!

1. В окне настроек выберите **"Сеть"**

2. **Адаптер 1 (обязательно):**
   - Галочка "Включить сетевой адаптер" = ВКЛ
   - **Тип подключения:** `NAT`
   - Это даст виртуалке доступ в интернет

3. **Адаптер 2 (обязательно для доступа извне):**
   - Перейдите на вкладку "Адаптер 2"
   - Галочка "Включить сетевой адаптер" = ВКЛ
   - **Тип подключения:** `Сетевой мост` (Bridged Adapter)
   - **Имя:** выберите ваш сетевой адаптер (обычно "Realtek...", "Intel...", "Wi-Fi...")
   - Нажмите OK

> **Что это значит:**
> - NAT — виртуалка ходит в интернет через ваш компьютер
> - Сетевой мост — виртуалка получает свой собственный IP в вашей сети (как отдельный компьютер)

#### 2.2.4 Установка Ubuntu Server

1. **Запустите виртуальную машину:**
   - Выберите "AzuraCast" в списке
   - Нажмите "Запустить" (зелёная стрелка)

2. **Начало установки:**
   - В появившемся окне выберите язык (English или русский)
   - Выберите "Install Ubuntu Server"
   - Нажмите Enter

3. **Настройки установки (можно нажимать Enter на большинстве пунктов):**
   - Keyboard layout: Done (по умолчанию)
   - Installation type: Done (по умолчанию)
   - Network connections: Done (DHCP должен работать автоматически)
   - Storage configuration: Done → Continue → Done

4. **Создание пользователя:**
   - Your name: `admin`
   - Your server's name: `azuracast`
   - Pick a username: `admin`
   - Choose a password: `ваш_пароль` (ЗАПОМНИТЕ ЕГО!)
   - Confirm password: повторите пароль
   - Done

5. **SSH Setup (ВАЖНО):**
   - Галочка "Install OpenSSH server" = ВКЛ
   - Done
   - Skip additional snaps (не выбираем ничего)
   - Ждём завершения установки (5-10 минут)

6. **После установки:**
   - Нажмите "Reboot Now"
   - При сообщении про CD-ROM — нажмите Enter

7. **Вход в систему:**
   - Login: `admin`
   - Password: ваш пароль
   - Введите команды после `$`

#### 2.2.5 Подключение к виртуалке через SSH (удобнее)

> Вместо работы в окне VirtualBox (где нельзя копировать-вставлять), лучше подключиться через SSH из Windows.

1. **Узнайте IP виртуалки:**
   ```bash
   ip addr show
   ```
   Ищите строку вида `inet 192.168.1.XXX` под интерфейсом `enp0s8` или `eth1`

2. **В Windows откройте PowerShell или CMD:**
   ```cmd
   ssh admin@192.168.1.XXX
   ```
   (замените XXX на адрес из предыдущего шага)

3. Введите "yes" для принятия ключа, затем пароль

> **Если ssh не найден в Windows:**  
> Windows 10/11 обычно имеет встроенный SSH. Если нет — установите PuTTY: https://www.putty.org

#### 2.2.6 Установка AzuraCast на виртуалку

Теперь, когда вы подключены по SSH, выполните команды:

1. **Обновите систему:**
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

2. **Установите Docker:**
   ```bash
   curl -fsSL https://get.docker.com | sudo sh
   ```

3. **Добавьте пользователя в группу docker:**
   ```bash
   sudo usermod -aG docker $USER
   ```
   После этого **переподключитесь** по SSH (выйдите и войдите снова)

4. **Установите AzuraCast:**
   ```bash
   mkdir -p /var/azuracast
   cd /var/azuracast
   curl -fsSL https://raw.githubusercontent.com/AzuraCast/azuracast/main/docker.sh > docker.sh
   chmod a+x docker.sh
   ./docker.sh install
   ```

5. **Дождитесь установки** (10-15 минут, скачается ~2 GB)

6. **Проверьте что всё работает:**
   - В Windows откройте браузер
   - Перейдите по адресу: `http://192.168.1.XXX` (IP виртуалки)
   - Должна открыться страница AzuraCast

#### 2.2.7 Настройка Shared Folder (общая папка с музыкой)

Чтобы загружать музыку с Windows на виртуалку:

1. **В VirtualBox (машина должна быть выключена):**
   - Выберите машину "AzuraCast"
   - Настроить → Общие папки
   - Нажмите значок папки с плюсом
   - Путь к папке: выберите папку с музыкой на Windows
   - Имя папки: `music`
   - Галочка "Автоматическое монтирование" = ВКЛ
   - Точка монтирования: `/mnt/music`
   - OK → OK

2. **В виртуалке установите Guest Additions:**
   - Запустите виртуалку
   - В меню VirtualBox: Devices → Insert Guest Additions CD Image
   - В терминале:
   ```bash
   sudo apt install build-essential dkms linux-headers-$(uname -r)
   sudo mount /dev/cdrom /mnt
   cd /mnt
   sudo ./VBoxLinuxAdditions.run
   sudo reboot
   ```

3. **После перезагрузки папка будет доступна как `/mnt/music`**

#### 2.2.8 Управление виртуальной машиной

| Действие | Как сделать |
|----------|-------------|
| Запустить | VirtualBox → Выбрать машину → Запустить |

#### 2.2.9 Решение проблем VirtualBox

| Проблема | Решение |
|----------|---------|
| "VT-x is disabled in BIOS" | Войдите в BIOS (F2/Del при загрузке) → включите Virtualization Technology / VT-x |

| Нет сети | Проверьте настройки сети (NAT + Bridged) |
| Не монтируется общая папка | Установите Guest Additions, добавьте пользователя в группу vboxsf |
| IP постоянно меняется | Настройте статический IP в Ubuntu или резервируйте IP на роутере |
| Виртуалка "зависла" | Меню Machine → Reset или ACPI Shutdown |

### ШАГ 4 — Проброс портов (ОЧЕНЬ ПОДРОБНО)

> **Что такое проброс портов и зачем он нужен?**
>
> Когда радио работает на вашем компьютере или в локальной сети, оно недоступно из интернета.
> "Проброс портов" — это настройка роутера, которая позволяет сделать сервис доступным из интернета.

#### 4.1 Понимание терминов

| Термин | Простое объяснение |
|--------|-------------------|
| IP адрес | Уникальный номер устройства в сети (как телефонный номер) |
| Порт | "Дверь" в устройство, через которую заходят данные |
| Локальный IP | Адрес внутри вашей сети (начинается с 192.168.x.x или 10.x.x.x) |
| Публичный IP | Адрес видимый из интернета (выдаёт провайдер) |
| NAT | Технология, позволяющая нескольким устройствам использовать один публичный IP |
| Проброс портов | Правило на роутере: "все запросы на порт X отправь на компьютер Y" |

#### 4.2 Проверка вашего публичного IP

1. Откройте браузер и перейдите на https://2ip.ru или https://whatismyip.com
2. Запишите показанный IP — это ваш публичный адрес

**Важно:** Если IP начинается с 100.x.x.x — это CGNAT (операторский NAT), проброс портов невозможен без обращения к провайдеру.

#### 4.3 Настройка статического локального IP

Чтобы проброс работал всегда, компьютер должен иметь постоянный локальный IP:

**Windows:**
1. Нажмите Win+R, введите `cmd`
2. Введите: `ipconfig`
3. Запишите:
   - IPv4-адрес (например, 192.168.1.100)
   - Основной шлюз (например, 192.168.1.1) — это адрес роутера

**Настройка статического IP на роутере (общий алгоритм):**
1. Откройте браузер и введите адрес шлюза (192.168.1.1)
2. Войдите (логин/пароль обычно admin/admin или на наклейке роутера)
3. Найдите раздел "DHCP" или "Локальная сеть"
4. Найдите "Резервирование адресов" или "Static DHCP"
5. Добавьте привязку MAC-адреса вашего компьютера к IP (например, 192.168.1.100)

#### 4.4 Настройка проброса портов

**Общий алгоритм для большинства роутеров:**

1. Войдите в веб-интерфейс роутера (http://192.168.1.1)

2. Найдите раздел:
   - Keenetic: "Порт проброса" или "NAT"
   - TP-Link: "Forwarding" → "Virtual Servers"
   - Asus: "WAN" → "Virtual Server / Port Forwarding"
   - MikroTik: IP → Firewall → NAT

3. Создайте правило:

| Параметр | Значение | Объяснение |
|----------|----------|------------|
| External Port | 80 | Порт, на который заходят из интернета |
| Internal Port | 80 | Порт на вашем компьютере |
| Internal IP | 192.168.1.100 | Локальный IP вашего компьютера |
| Protocol | TCP | Протокол (обычно TCP) |

4. Для HTTPS добавьте правило для порта 443

5. Сохраните настройки

#### 4.5 Проверка проброса

1. С телефона отключите WiFi и перейдите по адресу:
   ```
   http://ВАШ_ПУБЛИЧНЫЙ_IP:80
   ```

2. Если открывается AzuraCast — проброс работает!

#### 4.6 Альтернативы пробросу портов

Если проброс невозможен (CGNAT, ограничения провайдера):

**Вариант А: Cloudflare Tunnel (бесплатно)**
1. Зарегистрируйтесь на Cloudflare
2. Добавьте домен (можно купить у Cloudflare или перенести)
3. Установите cloudflared на сервер:
   ```bash
   # Linux
   curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 -o cloudflared
   chmod +x cloudflared
   
   # Авторизация
   ./cloudflared tunnel login
   
   # Создание туннеля
   ./cloudflared tunnel create azuracast
   
   # Запуск туннеля
   ./cloudflared tunnel run --url http://localhost:80 azuracast
   ```

**Вариант Б: ngrok (для тестирования)**
```bash
# Установка
npm install -g ngrok

# Запуск
ngrok http 80
```
ngrok даст вам публичный URL типа `https://xyz123.ngrok.io`

## 7. Частые ошибки и их решения

### Ошибка: "Таймаут загрузки"

**Симптомы:** При нажатии Play появляется сообщение "Таймаут загрузки"

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| Аудиопоток недоступен | Проверьте URL потока в браузере |
| Проблема с HTTPS | Убедитесь что SSL сертификат валидный |
| CORS ошибка | Настройте CORS на сервере AzuraCast |
| Сервер недоступен | Проверьте что AzuraCast запущен |

**Как проверить URL потока:**
1. Откройте URL потока в браузере
2. Должно начаться воспроизведение или скачивание файла

### Ошибка: "Ошибка сети"

**Симптомы:** Появляется сообщение "Ошибка сети" или "MEDIA_ERR_NETWORK"

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| Нет интернета | Проверьте соединение |
| Сервер недоступен | Проверьте статус AzuraCast |
| Блокировка провайдером | Попробуйте VPN |

### Ошибка: "Ошибка декодирования"

**Симптомы:** На iOS появляется "Ошибка декодирования" или аудио "заикается"

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| Неверный Content-Type | Убедитесь что сервер отдаёт `audio/mpeg` |
| Проблема с Icy-Metadata | Отключите метаданные в потоке |
| Проблема с gzip | Отключите сжатие для аудиопотока |

**Для iOS:** Приложение автоматически переключается в Fallback Mode, где визуализатор работает в симуляторе.

### Ошибка: Telegram Mini App не открывается

**Симптомы:** При переходе по ссылке ничего не происходит или открывается браузер

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| URL не HTTPS | Mini App требует HTTPS |
| URL не добавлен в BotFather | Выполните `/newapp` в @BotFather |
| Telegram старой версии | Обновите Telegram |

### Ошибка: Визуализатор не работает

**Симптомы:** Полосы эквалайзера не двигаются

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| iOS устройство | Это нормально — используется fallback режим |
| WebAudio не инициализирован | Нажмите Play ещё раз |
| Браузер не поддерживает Web Audio | Обновите браузер |

### Ошибка: Эквалайзер не влияет на звук

**Симптомы:** Изменение слайдеров не меняет звук

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| iOS устройство | WebAudio ограничен на iOS — эквалайзер не работает |
| Fallback режим | При ошибке WebAudio приложение переключается в fallback |

**Важно:** На iOS эквалайзер технически не может работать из-за ограничений Safari.

### Ошибка: Счётчик слушателей не работает

**Симптомы:** Показывает 0 или не обновляется

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| Worker не развёрнут | Разверните listeners-worker на Cloudflare |
| D1 база не создана | Создайте D1 database и таблицу listeners |
| CORS ошибка | Проверьте заголовки Worker |

**Создание D1 таблицы:**
```sql
CREATE TABLE listeners (
  user_id INTEGER PRIMARY KEY,
  first_name TEXT,
  last_name TEXT,
  username TEXT,
  is_admin INTEGER DEFAULT 0,
  is_telegram INTEGER DEFAULT 0,
  last_heartbeat INTEGER
);
```

### Ошибка: Название трека не обновляется

**Симптомы:** Показывает старое название или "DJ GooD OFF FM"

**Причины и решения:**

| Причина | Решение |
|---------|---------|
| Worker не отвечает | Проверьте статус nowplaying-worker |
| AzuraCast API недоступен | Проверьте `/api/nowplaying` в браузере |
| Кеширование | Добавьте `_t=timestamp` к запросу |

## 8. FAQ

### Общие вопросы

**Q: Как добавить свой логотип?**
> A: Замените файл `public/logo.png` на свой. Рекомендуемый размер: 512x512 пикселей.

**Q: Как изменить название станции?**
> A: В файле `RadioMiniApp.tsx` измените `STATION_NAME = 'DJ GooD OFF FM'` на своё.

**Q: Как изменить частоту обновления трека?**
> A: В `RadioMiniApp.tsx` найдите `setInterval(fetchCurrentTrack, 5000)` — измените 5000 (миллисекунды) на нужное значение.

**Q: Можно ли убрать рекламу из метаданных трека?**
> A: Worker автоматически очищает URL, Camelot keys, Energy levels и другой мусор. Если остались проблемы — добавьте паттерны в `cleanTrackTitle()` в `nowplaying-worker.js`.

### Технические вопросы

**Q: Почему на iOS нет эквалайзера?**
> A: Safari на iOS ограничивает Web Audio API — нельзя использовать `createMediaElementSource` с элементами из другого домена. Это ограничение Apple.

**Q: Как увеличить максимальную громкость?**
> A: Измените коэффициент в строке `(volume / 100) * 2.5`. 2.5 = 250%, 3.0 = 300% и т.д.

**Q: Как добавить новый пресет эквалайзера?**
> A: В `RadioMiniApp.tsx` найдите `EQ_PRESETS` и добавьте:
> ```typescript
> myPreset: { name: 'Мой Пресет', bass: 4, mid: 2, treble: -2 },
> ```

**Q: Как включить сохранение настроек эквалайзера?**
> A: Настройки уже сохраняются в localStorage. При перезагрузке они восстановятся.

### Вопросы развёртывания

**Q: Сколько стоит хостинг?**
> A: Vercel (frontend) — бесплатно для personal проектов. Cloudflare Workers — 100,000 запросов/день бесплатно. AzuraCast нужен свой сервер (от $4-12/мес).

**Q: Можно ли хостить всё на одном сервере?**
> A: Да, но для Telegram Mini App нужен HTTPS. Либо настройте SSL на сервере, либо используйте Cloudflare Tunnel.

**Q: Как масштабировать под много слушателей?**
> A: Используйте CDN для аудиопотока (Cloudflare Stream, Icecast relay) и кешируйте запросы к API.

## Приложение А: Структура API

### GET /api/now-playing

**Описание:** Получение информации о текущем треке

**Ответ:**
```json
{
  "title": "Artist - Title (Mix)",
  "artist": "Artist",
  "listeners": 5,
  "online": true,
  "art": "https://...",
  "duration": 240,
  "elapsed": 120
}
```

### GET /api/cover?artist=Artist&title=Title

**Описание:** Поиск обложки трека

**Параметры:**
- `artist` — имя артиста
- `title` — название трека
- `azuracast_art` — (опционально) URL обложки от AzuraCast

**Ответ:**
```json
{
  "cover": "https://...",
  "source": "lastfm"
}
```

### POST /api/listener

**Описание:** Регистрация слушателя

**Тело запроса:**
```json
{
  "user_id": 123456789,
  "first_name": "Иван",
  "action": "open",
  "isTelegram": true
}
```

**Действия:**
- `open` — новый слушатель
- `heartbeat` — подтверждение активности (каждые 30 сек)
- `close` — слушатель ушёл

**Ответ:**
```json
{
  "success": true,
  "total": 5
}
```
